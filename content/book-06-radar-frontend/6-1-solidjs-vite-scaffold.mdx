**Team Radar** is the manager dashboard — SolidJS + Vite, not React.

<RadarAppShell client:load />

## Quick start

```bash
pnpm build:wasm          # once
pnpm compose:up
pnpm analyzer:dev & pnpm ingestion:dev &
pnpm dev:radar           # http://localhost:5174
```

## Vite proxy

`vite.config.ts` forwards `/api/*` to analyzer `:8082` — same-origin for the browser (lesson 0.7).
