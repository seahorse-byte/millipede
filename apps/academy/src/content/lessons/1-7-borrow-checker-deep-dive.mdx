The **borrow checker** is Rust's static proof that references never outlive data or alias illegally.

| Borrow | Syntax | Rule |
|--------|--------|------|
| Shared | `&T` | Many readers OR one writer |
| Mutable | `&mut T` | Exclusive — no other borrows |

## Lifetimes (preview)

When references appear in structs or return types, lifetime annotations (`'a`) tell the compiler how long borrows remain valid. Analyzer SQLx queries often return rows tied to connection lifetime.

## EM angle

Borrow errors in CI = cheaper than data races in prod.
