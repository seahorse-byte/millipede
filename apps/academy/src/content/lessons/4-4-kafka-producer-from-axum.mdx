Ingestion wraps the producer in `Option` — if Kafka is down, webhooks still return `accepted: true` with `kafka_status: unavailable`.

**IngestionProducerPanel** — simulate send vs broker failure.

## Producer config

```rust
ClientConfig::new()
    .set("bootstrap.servers", &kafka_brokers)
    .set("message.timeout.ms", "5000")
    .create::<FutureProducer>()
```

Default topic: `KAFKA_TOPIC=raw-dev-events`.
