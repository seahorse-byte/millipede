## Before you start

```bash
pnpm compose:up
pnpm evals:run && pnpm evals:write-metrics
pnpm build:wasm && pnpm dev:radar
```

Use the millipede-demo tmux layout — one pane per service, radar on `:5174`.

## Five beats

1. KPI row — friction + eval pass rate
2. Eval gate — `pnpm evals:run` or widget
3. Webhook curl — live feed updates
4. `/1on1` — WASM redaction
5. Close — gates replace heroics

Advance the widget checklist as you demo — reset between rehearsals.
