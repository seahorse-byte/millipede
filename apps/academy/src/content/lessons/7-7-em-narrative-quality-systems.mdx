## Stage 5 in one paragraph

Team Radar now ships **quality systems**: heuristic eval CI in `evals/`, Playwright smoke in `e2e/`, gateway SSE for live feeds, and four manager KPIs fed from Postgres. Stage 5 does not reshape the PDF stack — it adds release discipline borrowed from work repos.

Full reference: `docs/stage5-quality.md`

## Narrative beats for leadership

1. **Problem** — AI enrichment without gates is demo-ware
2. **System** — eval regression + e2e + latency budgets
3. **Outcome** — managers see eval pass rate on the same dashboard as sentiment
4. **Proof** — run evals and e2e in a mock class, not a slide deck
